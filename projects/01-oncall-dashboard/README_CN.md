# 📊 值班号工单数据分析平台

## AI驱动的运营分析产品


# 项目介绍


值班号工单数据分析平台是一个面向运营团队的 AI 辅助分析平台。

通过整合工单数据、指标体系和大模型分析能力，实现：

- 数据统一查看
- 指标自动计算
- 异常问题发现
- AI分析总结
- 周报自动生成


---

# 1. 项目背景


值班号每天产生大量机器人及人工工单。

相关数据分散在：

- 腾讯云
- 机器人后台
- 知识库
- 工单系统


运营人员需要：

1. 手动收集数据
2. 计算指标
3. 分析趋势
4. 制作周报


主要问题：

- 数据获取困难
- 分析效率低
- 问题定位慢
- 周报制作耗时


---

# 2. 用户与痛点


## 用户


- 产品运营
- 业务运营
- 产品经理


## 核心痛点


### 数据分散

多个系统之间缺少统一数据视图。


### 分析依赖人工

大量指标需要人工计算。


### 异常发现滞后

问题无法及时发现和定位。


### 周报重复劳动

运营人员需要重复整理数据。
