# 📊 Oncall Dashboard

## AI-powered Operation Analytics Platform


## Overview

Oncall Dashboard is an AI-assisted operation analytics platform designed to help operation teams monitor service performance, identify abnormal trends, and generate insights automatically.

The project explores how AI can enhance traditional operation workflows by combining data visualization, automated analysis, and LLM-powered insights.


---

# 1. Background

In daily operation scenarios, oncall systems generate a large volume of robot and human tickets.

However, operational data was distributed across multiple platforms:

- Cloud platforms
- Robot systems
- Knowledge bases
- Ticket management systems


Operators needed to manually collect data, calculate metrics, analyze problems, and create weekly reports.

This resulted in:

- High manual workload
- Low efficiency of problem discovery
- Difficulty identifying root causes
- Time-consuming reporting processes


---

# 2. User Problems


## Target Users

- Operation specialists
- Product managers


## Core Pain Points


### Data Fragmentation

Important operational data existed across different systems, making data collection inefficient.


### Manual Data Analysis

Operators spent significant time calculating indicators and comparing performance trends.


### Low Problem Detection Efficiency

Abnormal changes were difficult to discover quickly.


### Repetitive Reporting Work

Weekly reports required repeated manual organization.
